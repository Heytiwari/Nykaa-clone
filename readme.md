# 💄 Nykaa Clone

A modern and responsive **Nykaa-inspired beauty & fashion e-commerce website** built using **HTML and CSS**.

This project is created to practice **frontend development**, CSS layouts, dropdown menus, hover effects, animations, and e-commerce UI design.

---

## ✨ Features

* 🎀 Modern Nykaa-inspired UI
* 📌 Fixed promotional bar & navigation
* 🔍 Search box
* 🛍️ Shopping bag & user section
* 💄 Beauty categories
* 🏷️ Brands dropdown menu
* 💎 Luxe dropdown menu
* 👗 Nykaa Fashion dropdown menu
* 💅 Beauty Advice dropdown
* 🎯 Category mega menu
* 🔥 Animated sale/promotion bar
* 🖼️ Hero banner section
* 🎁 Deals & offers section
* 🌸 Mamonde product section
* ⭐ Best Brands section
* 📧 Newsletter subscription
* 📱 App download section
* 🚚 Benefits section
* 🔗 Footer with useful links
* ✨ Hover effects and CSS animations

---

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Flexbox**
* **CSS Grid**
* **CSS Animations**

This project focuses on practicing modern CSS techniques.

Used for navigation, cards, footer sections and horizontal layouts.

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Heytiwari/naykaa-clone.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! 🎉
